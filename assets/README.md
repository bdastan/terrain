# Assets

Ce dossier contient tous les assets de l'application Prime Work.

## Structure

- `images/` - Images et photos
- `icons/` - Icônes personnalisées
- `logo/` - Logo de l'application
- `fonts/` - Polices personnalisées (si nécessaire)
